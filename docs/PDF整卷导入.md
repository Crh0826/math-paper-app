# 整卷 PDF 导入（扫描卷 → 题目 + 图 + 答案）

面向「只有 PDF、没有 docx」的真卷：题目页是**扫描图**（没有文字层），答案页带文字层。
`tools/extract_exam_pdf.py` 把它拆成「每道题 + 裁好的插图 + 答案」，打成 ZIP 交给导入链路（t88）。

## 一、怎么用

```powershell
cd E:\OCR\app
python tools\extract_exam_pdf.py `
  --pdf "E:\crh\学习\中考\学习资料\【6】2026年C20二模试卷与答案\2026年C20二模物理及答案.pdf" `
  --subject physics --out out/_c20_physics --emit-docx out/_c20_physics/docx
```

| 参数 | 说明 |
|---|---|
| `--pdf` | 试卷 PDF（题目页可扫描，答案页要带文字层） |
| `--subject` | `subject_pk`（如 `physics`） |
| `--out` | 输出目录（默认 `out/_exam_<文件名>`） |
| `--layout paddle\|opencv` | 版面分析后端，默认 `paddle`（PaddleOCR-VL） |
| `--no-base / --no-width` | 第 1 题对应的库题号（默认 1 → `00001`），补零宽度默认 5 |
| `--question-pages / --answer-pages` | 手工指定页范围（默认按「文字层 ≥20 字」自动分） |
| `--emit-docx` | 额外生成 `<no>.docx`（题干 + 图），配 `MATH_APP_QBDIR` 就能让 paper 直接排版带图 |
| `--zip` | ZIP 路径（默认 `<out>.zip`） |

产物：

```
out/_c20_physics/
  questions.json        [{no,qno,qtype,stem,answer,figure:[…],subject,page}]
  images/0000N.png      按题裁的图（一图多张：0000N_2.png）
  report.json           统计：题数/带图题/图数/缺图题/缺答案/逐页明细/图号→bbox 表
  docx/0000N.docx       可选：题干 + 图（供 paper 排版）
out/_c20_physics.zip    questions.json + images/
```

## 二、版面分析：用的是哪一种

| 后端 | 谁在用 | 说明 |
|---|---|---|
| `paddle`（默认） | 真卷 **C20 二模物理** 实测 | PaddleOCR-VL 云端 job（一个页面一次，`block_bbox` + `block_content`）。文字块直接读题号/题干；**插图块的 `content` 为空**（真卷实测 30 个），图注「第N题图」另起一块 |
| `opencv`（回退） | 无网/无 token 时 | 二值化 → 抹掉长横竖线 → 行投影切带 → 「带高 > 中位带高 1.8×」判图。**只能给 bbox，读不出题号**，切题要人工给 `--numbers`（未实现） |

GLM-OCR 当前 **不可用**（`HTTP 429 余额不足`），本脚本不调用它。

C20 二模物理（10 页：1–6 扫描题页 / 7–10 答案页）实测：

| 项 | 结果 |
|---|---|
| 题数 | **23**（与答案页 1–23 对齐） |
| 图块 | **30**，其中 19 道题配上图，剩 4 道本来就是纯文字题 |
| 缺图（题干说「如图」却没图） | **0** |
| 答案 | **23/23** 解析出来（含选择题对照表 11–17） |
| 耗时 | ~7 s（6 页扫描页各一次 OCR job） |

## 三、切题与归属规则

1. **切题**：文字块以 `1．/1./1、/18\.`（Paddle 有时把 `．` 输出成 `\.`）开头即开新题；
   后面不带题号的文字块并入当前题的题干。
2. **卷首注意事项**：`你拿到/本试卷/请务必/考试结束/试题卷/答题卷` 开头的块在切题前摘掉
   —— 否则「1. 你拿到的试卷满分为 70 分」会被当成第 1 题。
3. **OCR 重号**：同页内题号必须单调递增，`5.…5.…` 的第二条按 `6` 处理（真卷第 6 题被读成 5）。
4. **跨页同号**：同一题号在多页各识别出一部分时合并（文本取长的、图取并集）。
5. **图归属**：优先按图注「第N题图」点名的题号（可跨页 —— 第 7/8 题图印在第 1 页底部）；
   没点名的图跟同页最近的已归属图，再退到「上方最近的题」。一题多图按 y 升序编号 1/2/3。
6. **图注合并**：图注块（`第N题图`）并进图块 bbox（图注在图下方或上方都认，±200px），
   并从文字流里摘掉，避免混进题干。

## 四、答案解析

答案页带文字层（真卷 853/1000/793/663 字），两种形态都解析：

* 行内：「`1．60； 2．人耳处；`」→ 到第一个 `；` 为止（含「（1）…（2）…」的多小问整段保留）；
* 对照表：「`题号 11 12 … 17` / `选项 D B D A C B C`」→ 选择题答案（比正文里零散的「17．选：C」更全）。
* `选：C` 前缀会剥掉。

与库里既有 23 题对拍（归一化：全角转半角、去空格、去引号）：**逐字一致 23/23、包含/数字齐全 23/23**。
库里的答案是「关键结果」，PDF 里是「完整解答」，所以除了逐字比，还判「库答案的数字/关键片段在 PDF 答案里都出现」。

## 六、已知限制

1. `opencv` 回退只给 bbox、**读不出题号**，单独用无法切题（真卷走 `paddle`）；它的「图/文」判别在真卷上没做精度标定。
2. 裁图按 `block_bbox` 外扩 6px，长边不足 **800px** 会等比放大；个别插图把相邻的「甲/乙/丙」标注切在框外（题面文字里仍保留）。
3. 选择题的**选项**是从题干里按 `A．B．C．D．` 切出来的；个别题（如第 15 题的四联图）选项与图混排会切不全，导入时会被
   「选择题必须有选项（≥2）」挡下 —— 需要在导入前手工补选项，或改为填空处理。
4. `--emit-docx` 生成的 docx 只用于排版取图；题面文字仍以库里 `text_plain` 为准。

## 七、数据质量修正（t91）

1. **试卷须知不再当题目**：`is_instruction()` 按关键词（你拿到 / 本试卷 / 请务必 / 考试结束 /
   考试时间 / 闭卷 / 请将答案 / 试题卷 / 答题卷 / 满分 / 注意事项 / 考生须知）识别说明段，
   切题时（含卷首裁剪）一律剔除，并记进 `report.json` 的 **`skipped_sections`**
   （页码 + 原文前 120 字 + 原因），**不进 questions.json**。C20 真卷剔掉 4 段（满分说明、两卷说明、
   答题卷要求、交回要求），题号从 1 开始就是真题。
2. **四联图选择题选项合并**：`split_options()` 用 `A．/A.` 标签切分（**顿号不算分隔符** ——
   「C、F 点等高」这种会误命中），允许选项之间夹着图块/图注（`第15题图`、`甲`/`乙`/`丙`/`丁`），
   切完再清掉这些噪声。切不出 ≥2 个选项时**保留该题**并标 `options_incomplete=true`
   （同时写进 `report.json.options_incomplete`），交由导入端拒绝或人工补，**不静默丢题**。
3. **图归属跨页**：图注「第N题图」在一次全局归属里按题号点名（真卷第 7/8 题图印在第 1 页底部、
   题目在第 2 页），y 归属仍限同页。
