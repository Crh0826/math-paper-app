# 让 AI 把 Word 题目转成 JSON（提示词）

> 适用场景：手里的题是 Word 文档（`.docx`），没有现成的 CSV / Excel / JSON。
> 与其让程序硬解 Word 版式，不如**把 Word 内容贴给任意 AI，让它按我们的格式输出 JSON**，再拖回「导入题库」——导入器本来就吃 JSON，这条路又快又稳。
>
> 页面入口：`http://127.0.0.1:8710/import` → 上传区上方的折叠块「**没有 JSON？让 AI 帮你转**」（可一键复制提示词、下载示例 JSON）。

## 三步就够了

1. **复制提示词**：把下面整段复制走（页面上的「复制提示词」按钮一步到位）。
2. **贴给任意 AI**：提示词 + 你从 Word 复制的题目文本一起发过去（ChatGPT / DeepSeek / 豆包 / 通义 / Kimi 都行，不用管是哪家）。
3. **存成 `.json` 再拖回来**：把 AI 返回的 JSON 原样存成 `qbank.json`，回到「导入题库」拖进来，先点「开始校验」看预览（不写库），没问题再勾「确认导入」。

示例文件：`http://127.0.0.1:8710/import/template.json`（1 道选择题 + 1 道填空题，可下载后照抄字段；题号故意用 99001 / 99002，不会覆盖你的真题）。

## 提示词全文（直接整段复制）

```text
你是题库格式转换器。下面我贴一段题目（从 Word 复制即可），请转成我需要的 JSON。
只输出 JSON，不要解释、不要 Markdown 代码块、不要省略号。

{"subject":"数学","grade":"七年级上","version":"沪科版","items":[{"no":"01001","qtype":"选择","stem":"…","options":["A. …","B. …","C. …","D. …"],"answer":"B","kp":"","chapter":""}]}

规则：
- no：5 位数字字符串，从 00001 顺序编，文件内不重复
- qtype：只能是「选择」「填空」「解答」
- stem：题干纯文本，公式保留原样（2x+1=5、x²、√3），不要改写或翻译
- options：仅选择题需要，4 项 A-D 开头；其他题型给 []
- answer：只写最终答案。选择写字母（B 或 AB）；填空/解答写答案本身；多解用英文逗号分隔（-1,2）；没有答案给 ""
- kp / chapter：能从原文看出才填，看不出给 ""
- 分数写 3/4，带分数写 1 3/4，圆周率写 π
- 一份材料里有多道题就逐题输出；只有一道就 1 项
- 不确定的字段宁可留空，不要编造
```

## 拿到 AI 的 JSON 之后

- **先校验再导入**：`/import` 选文件 →「开始校验」→ 看「合法行 / 问题行」与逐行原因；这一步不写库。
- **题号别撞车**：`no` 是主键，重复的题号会按「内容相同=跳过、内容变了=更新」处理，不会产生两行。
- **公式保持原样**：`stem` 里不要让人把 `x²` 改写成 `x^2`、把 `√3` 改写成 `sqrt(3)`，卷面排版按原文渲染。
- **不确定就留空**：`kp` / `chapter` 留空不影响导入，只是失去按知识点抽题的便利。
- **AI 偶尔会加解释或代码块**：让它在提示词约束下「只输出 JSON」；真加了就把第一行到最后的 `{ … }` 之间留下，其余删掉再存。

## 文件字段速查

| 字段 | 必填 | 说明 |
|---|---|---|
| `no` | 是 | 题号，5 位数字字符串，文件内唯一 |
| `qtype` | 是 | 「选择」「填空」「解答」 |
| `stem` | 是 | 题干纯文本，公式原样 |
| `options` | 选择题必填 | `["A. …","B. …","C. …","D. …"]`；其他题型 `[]` |
| `answer` | 是 | 最终答案：选择写字母（`B` / `AB`）；填空解答写答案本身；多解英文逗号（`-1,2`） |
| `kp` / `chapter` | 否 | 知识点编号 / 章节名，看不出就 `""` |

> 也可以给 Excel / CSV：表头用「题号 / 题型 / 题干 / 答案 / 解析 / 知识点 / 章节」，选项拆成 A/B/C/D 四列或一列用竖线 `A．1|B．2|C．3|D．4`。
