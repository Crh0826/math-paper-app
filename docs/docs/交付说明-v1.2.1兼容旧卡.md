# v1.2.1 更新说明（2026-11-01）

**一句话：v1.2 里旧版答题卡被判「请重新打印」，这是个回归 bug，这一版修好了。**

## 兼容旧版答题卡（4×4）

| 卡片 | 判卷方式 | 结果 |
|---|---|---|
| **旧卡 + 卷号在库里** | 按 manifest 每题 `id_box.bits`（16 位）解出「卷内第几题」，用 manifest 里的几何与答案键判 | ✅ 正常判分（实测 `P20261031-007` + 真实老照片 → `1/2`，与历史记录一致） |
| **旧卡 + 卷号不在库** | 旧卡只标「第几题」不标题号，无法脱离卷子判 | 明确报 `legacy_card_need_pid`：「旧卡需要卷号：回判卷页选上这份卷子；卷子找不到就重打新卡」 |
| **新卡（5×5）+ 有/无卷号** | 25 位解出**题号**，可直接查题库判 | ✅ 有卷号走快路径，没卷号走每题标识 |
| 我真不认识的标识（非 16/25 位） | — | `legacy_card`「这张答题卡是旧版本，请重新打印」 |

实现口径：判卷**只看每道题 `id_box.bits` 的长度**（16 → 旧卡题序，25 → 新卡题号），不看全局常量，也不重算几何——manifest 本身是自描述的。
比对不一致 → `pid_mismatch`（拍的确实不是这份卷子），不会拿错坐标硬判。

## 顺带修的

- **新卡版本号**：`manifest.card.version` 从写死 `1` 改为 `CARD_VERSION=2`，二维码 payload 增加 `"v":2`（以前新卡自称 v1，会误导任何按版本判断的代码）。
- **答题卡 A4 自检**：`build_card` 复用 `paper.check_pdf_a4`，并在返回的 `health` 里给 `page_size_pt / pages / a4_ok`。
