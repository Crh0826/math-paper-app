# v1.2 更新说明（2026-11-01）

在 v1.1（2026-10-31 定版：760→859→920 条测试全绿、端到端 8 项通过）基础上，按你的反馈与代码审查意见做了 10 项改动。

## 新增能力

### 1. 设置页：自己填 API Key（P0）
`/settings`，导航新增「设置」。
- 4 个识别后端：**PaddleOCR-VL 云端** / **OpenAI 兼容视觉模型** / **本机离线** / **全人工**；
- 各后端的 token / key / base_url / model 自己填，**页面永不明文回显**（只显示「已配置 · 尾号 ac06」），留空 = 不修改，带「清除」；
- **测试连接**：内置 900×260 测试图真跑一次识别，结果分五类——成功 / 连通但没解析出内容 / 鉴权或额度 / 网络 / 其他异常，**只有鉴权或额度问题才提示查 Key**；
- 保存只改 `config.json` 的 `ocr` 段，写前备 `config.json.bak`，其它配置项原样保留；
- 本机离线后端会**探测当前机器是否可用**（Windows + winsdk），不可用时明确标「本机不支持」并说明原因（本机 Python 3.14 装不上 winsdk），不会假装能用。

### 2. 去掉硬编码路径
新增 `paths.py`。题库 / 数据 / 产物目录解析顺序：环境变量（`MATH_APP_QBDIR` / `MATH_APP_DATA` / `MATH_APP_OUT`）→ `config.json` 的 `paths` → 程序同目录（`qbank/`）→ 老路径回退。
仓库里不再有 `E:\OCR\app` 这种写死路径，clone 到任意目录可跑。

### 3. 题库导入接口（多学科）
```bash
python import_qbank.py --from json|excel|csv|docx --file <路径> [--db] [--report] [--dry-run]
```
- Excel/CSV 支持表头别名（题号/编号、题型/类型、题干/答案/解析/知识点/章节…），选项可四列或竖线分隔；
- **幂等**：按题号 upsert，重复导入只更新；
- 坏行只进报告不落库；报告 `data/import_report.json`；
- 数据库新增 `subjects` 与 `subject_pk`，同一套程序可挂多个学科（老库自动迁移）。

### 4. 打印容错
- **校准页**：卷面 PDF 第 1 页，100×100mm 红框 + 10mm 刻度尺 + A4 外框，打印后拿尺子量，不是 100mm 就说明被缩放；
- **A4 自检**：生成阶段校验每页 595.28×841.89pt（±0.5），不是就抛 `pdf_not_a4`（带页号与实测尺寸），不会印出一张对不上的卡；
- 校准页默认开，可在组卷页取消；它不参与「末页填充率」判定，也不影响答题卡页码。

### 5. 手机拍照即时反馈
- 标定失败不再只给一句话：返回结构化诊断（检出几角 / 缺哪个角 / 倾斜或旋转角度 / 纸张占比 / 是否反光），并**在原图上画诊断图**（绿圈=检出、红箭头=让某个角入镜、顶部红条写原因）；
- 成功入镜的正常照片不产生诊断图。

### 6. 判卷免选卷号 + 每题唯一标识
- 上传页卷号改成下拉，首项「**自动识别（推荐）**」：从答题卡二维码取卷号；
- 每题标识从 4×4（题序）升级为 **5×5（编码题号 + CRC-5）**，因此**卷号在库里查不到时也能按题判卷**（换电脑、卷子被删、复印件都行）；
- ⚠️ **旧版答题卡不兼容**：重判会提示「这张答题卡是旧版本，请重新打印答题卡」。

### 7. 判卷记录页
`/records`：列出历史判卷（时间 / 卷子 / 得分 / 待确认 / 状态），支持按卷子筛、只看待确认、搜索、删除；窄屏为卡片式。

### 8. 跨平台（LibreOffice 回退）
Word 不可用时自动尝试 `soffice --headless --convert-to pdf`，让 macOS / Linux 也能出卷；都没有才报 `no_backend` 并给安装建议。页面与 `/health` 显示当前 PDF 后端。
**⚠️ 诚实说明：LibreOffice 回退只用伪造的 `soffice` 脚本验证过链路，未在真实 LibreOffice 上实测。**

### 9. 便携版 exe
PyInstaller onedir + `qbank/` 题库 + 一键启动器：
- zip **219.5 MB**（230,166,570 字节）/ 解压 **503.3 MB / 23,147 文件**（首次运行后 624.9 MB，多出的是 120MB 数据库与 out/）
- 冷启动到 `/healthz` 200 = **1.30 秒**（干净目录 `D:\test_v12` 全新解压），解压 8.3 秒
- `--check` 自检 exit 0（题库 22,898 / DB 120MB / PDF 后端 Word / 版本行 v1.2）
- 冒烟：`/healthz` ok、`/submissions` 200、组 10 题卷 → `paper.pdf` **3 页 A4**（校准 1 + 内容 2）+ `card.pdf`
- 局域网模式带 4 位访问码
- **出包前自动校验答题卡是 5×5 新版**（防止把旧卡打进包），实测 `PASS: ID_GRID=5`

### 10. seed 自动变更
组卷表单 seed 留空 = **每次自动换一套**（预览页显示实际 seed，可复制复现）；填数字 = 精确复现；预览页有「同参数换一套」。

## 修复的正确性问题

| 问题 | 影响 | 修复 |
|---|---|---|
| 表格里带图的题入卷后 Word 打不开 | 398 题（1.7%），每 3 份卷子约 1 份废 | 三层修复：table token 收集媒体 → 序列化 → 拼装重映射 rId |
| 跨盘搬 PDF 必失败 + 每次泄漏 Word 进程 | 转 PDF 失败；5 次吃 1GB | copyfile 到目标卷再本卷 os.replace；按 PID 等 Word 退出再清理 |
| 科学计数法乘号被 OCR 丢掉后判错 | 含乘号答案 100 题 | `1.6×(10)^(12)` = `1.6 10^ 12` = `1.6e12` 全部等价 |
| 多值答案只识别出一部分被判错 | 多空解答题 | 改判「待确认（缺 N 个值）」 |
| 解答题默认留 8 段书写区 | 24 题 6 页 → 3 页 | 默认全 0（答案写在答题卡上） |
| 判卷永远卡在「识别中」 | 用户实测等 2 小时 | 上传后自动起后台识别 + 轮询兜底 + 失败不再假装识别中 |
| 带分数 `21(1)/(4)` 判错 | 146 题 | 支持带分数三种写法 |
