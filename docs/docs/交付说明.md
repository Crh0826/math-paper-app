## 1. 它是什么

从你给的 22,898 道七年级数学题（沪科版 2024 上学期）里**按题型数量 + 章节/知识点范围**组卷，
生成**可打印的 A4 卷子 + 机读答题卡**；你手写填完拍照上传，它**自动判选择题、识别填空与解答的最终答案**，
并**按错题自动生成针对性训练卷**。

判卷口径按你的要求：**只看选择题序号与填空/解答的最终答案，不判解题过程**（过程区只作书写空间）。

## 2. 怎么用（三步）

```
① 双击 E:\OCR\app\start.bat          → 浏览器自动打开 http://127.0.0.1:8710
② 组卷页填：选择/填空/解答数量 + 章节或知识点 + seed → 提交（约 7~40 秒排版）
   → 预览页下载 print.pdf（卷面在前、答题卡在后）→ 打印
③ 手写作答 → 判卷页选这张卷、上传答题卡照片
   → 选择题立即出分；填空/解答显示"识别中（约 30 秒）"
   → 待确认队列逐项确认/改判 → 结果页「用错题生成训练卷」
```

**打印要求（很重要）**：A4、**100% 比例**，不要勾"适应页面/缩放以适合纸张"——缩放会让答题卡坐标对不上。

**拍照要求**：一次拍一页、答题卡四角黑色方块**全部进入画面**、正对倾斜 ≤30°、别开闪光灯、别让手挡住角、宽度 ≥1600px。

### 4.3 范围界定与平台边界

- **"如图无图"语料缺陷**：约 **2,000~3,000 题**（文本匹配口径 2,932；严格判定口径 2,032），组卷**默认排除**，不会印出无解的题。
- **薄知识点**：`5.0 数据的收集与整理·综合` 仅 4 题、`5.2 统计图与频数分布` 8 题、`4.5 余角补角` 12 题、`4.6 动点与角度` 14 题、`4.0 几何综合` 33 题。UI 会标"仅 N 题"，要多了会明确报"还差多少"。
- **「其他」题型 64 题**：组卷不支持该题型，不会出现在任何卷子上（范围界定，不是缺陷）。
- **训练卷允许同族跨题型**（如选择错题配到填空题）：取题顺序 题族 → 知识点 → 章节 → 同题型。
- **判分口径**：代数化简不判（`3a+2a` vs `5a`）、多空按位判（防两空错配送分）、`1/3` 写成 `0.33` 会进待确认。
- **平台**：只在 **Windows + 本机 Microsoft Word** 上验证。无 Word 时降级只验到「提示页 + 答题卡仍可打印」，**降级后的 PDF 打印效果未验**。

## 7. 技术要点（给维护者）

- **公式保真**：题目公式有两种编码（原生 OMML 与 MathType/WMF 对象），提取层逐 token 保留，拼装层做 rId 重映射 + 媒体注册。
  **媒体铁律**：任何带 `r:embed/r:id/r:link` 的 XML（**包括表格**）插入新文档前必须重映射关系并注册二进制，漏一个就是坏文件。
- **判卷不需要理解版面**：卷子是软件生成的，每题坐标/选项数/答案键都在 `manifest` 里，照片经 ArUco 四角标定复原后按清单取数。
- **两阶段判卷**：选择题毫秒级出分；填空/解答拼一张长图后走一次云端 OCR job（约 30 秒），失败整批降级为"待确认"。
- **可核对性**：每题可看"为什么这么判"（识别文本 / 标准答案 / 归一化理由 / 待确认原因 / 墨迹占比），并生成整页批注图。
