文件格式怎么排

CSV / Excel 第一行是表头，至少要有 题号、题型、 题干、答案 四列；选项可以拆成 A/B/C/D 四列， 也可以一列里用竖线：A．1|B．2|C．3|D．4。

JSON 用 {"items": [...]} 或裸数组；每题字段： no / qtype / stem / options / answer / analysis / kp_id / chapter。 表头别名（题号/编号、题型/类型、题干/题目、答案/正确答案、解析、知识点/考点、章节、图片）都认。
